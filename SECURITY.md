# Security

This is an early local MVP, not a hostile multi-tenant sandbox. Read [the security model](docs/security.md) before use. Only version 0.1 is currently maintained; there is no security response SLA.

Do not disclose exploitable vulnerabilities or credentials in public issues. Once this repository has an upstream host, use its private vulnerability-reporting facility where enabled, or contact the maintainer privately through that host. No public upstream or security contact address has been configured in this local repository. Do not assume a public issue is a private reporting channel.
