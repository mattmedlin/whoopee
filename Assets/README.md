# Listening reference

`fart-breviceps.mp3` is the public high-quality MP3 preview of **Fart 1** by **Breviceps** (Freesound sound 445998).

- Source: https://freesound.org/people/Breviceps/sounds/445998/
- Download: https://cdn.freesound.org/previews/445/445998_9159316-hq.mp3
- License: CC0 1.0 Universal, https://creativecommons.org/publicdomain/zero/1.0/
- Retrieved: 2026-10-16

The author explicitly dedicates the recording to the public domain. The original WAV requires login; this project keeps the freely accessible MP3 preview as a listening reference. It is used offline to identify resonator coefficients and a fitted contact-force trajectory. The plugin does not load or play the audio. See `tools/MODEL.md` for the distinction between this identified model and an autonomous anatomical simulation.
